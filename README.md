# antora-supplemental organization: .github

Purpose:
This repository provides GitHub organization-level community and workflow configuration for the organization's public repositories.

Brand assets:
Org mark and avatar files live under `assets/` (`logo.svg`, `logo-avatar.svg`, `logo-256.png`). Upload `logo-256.png` in GitHub organization profile settings when changing the avatar.

Workflow templates:
To add organization workflow starter templates, place template files under `workflow-templates/` following GitHub's documentation:
https://docs.github.com/en/actions/using-workflows/creating-starter-workflows-for-your-organization
